# ⏳ Новогодний таймер обратного отсчета

Интерактивный веб-сайт с обратным отсчетом до Нового года. Создан в рамках учебного проекта по информационным технологиям.

## 🚀 Демо.     
Посмотреть работающий сайт можно по ссылке: 
**[https://kmvanyaa.github.io/timer123/](https://kmvanyaa.github.io/timer123/)**

## ✨ Основные возможности:
*   **Точный таймер:** Считает дни, часы, минуты и секунды до праздника.
*   **Смена тем:** Переключение между светлой и темной темой (выбор сохраняется в браузере).
*   **Праздничная атмосфера:** Анимированный снегопад, мерцающие звезды, падающие кометы, гирлянда и новогодний шарик.
*   **Интерактив:** 
    *   Салют при клике в любом месте экрана.
    *   Кликабельная гирлянда с предсказаниями.
    *   Голосовое озвучивание таймера (Text-to-Speech).
    *   Волшебный шлейф за курсором мыши.
*   **Пасхалки:** Секретное слово, вызывающее мега-салют, и глитч-эффект на заголовке.
*   **Полезные фишки:** Прогресс-бар прошедшего года, счетчик посещений, текущее время и дата.

## 🛠️ Технологии:
*   HTML5
*   CSS3 (Анимации, градиенты, медиа-запросы)
*   JavaScript (Vanilla JS, работа с DOM, LocalStorage, Web Speech API)
